# matera

MATERA restaurant website built with Next.js, React, and Tailwind CSS.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Motion (`motion/react`) for UI animation

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

3. Open:

`http://localhost:3000`

## Build for Production

```bash
npm run build
npm run start
```

## Project Notes

- Localized routes:
  - `/en`
  - `/ar`
- Dictionaries are in:
  - `src/dictionaries/en.json`
  - `src/dictionaries/ar.json`
- Static assets are in:
  - `public/images`
  - `public/asset`
